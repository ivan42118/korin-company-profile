# Project Context: PT Korin Technomic Company Profile

Last analyzed: 2026-05-30

## Overview

This repository is a single-page company profile website for PT Korin Technomic, an Indonesian precision plastic injection and footwear component manufacturer. The site is built as a polished marketing/company profile page with a full-screen video hero, machine capability cards, production flow storytelling, product cards, workflow explanation, facility imagery, and a contact inquiry form.

The implementation is largely complete as a static frontend. It builds successfully with Next.js 16.2.6 and Turbopack.

## Project Architecture

The app uses the Next.js App Router.

- `app/layout.tsx` defines the root HTML document, metadata, global fonts, and imports `app/globals.css`.
- `app/page.tsx` composes the full landing page from layout, section, and UI components.
- `content.ts` centralizes most site data: company contact details, nav links, stats, products, machines, archived workflow steps, facility images, and footer product links.
- `components/layout` contains global layout pieces: navbar and footer.
- `components/sections` contains full-page or page-band sections.
- `components/ui` contains reusable presentation and animation primitives.
- `public` contains the main static media library, including product photos, factory/machine images, SVG placeholders, and the hero video.
- `assets` contains the imported Korin logo used by navbar and footer.

There is only one public route:

- `/` from `app/page.tsx`
- `/_not-found` generated by Next.js

The page is statically prerendered.

## App Composition

`app/page.tsx` renders this order:

1. `LenisProvider`
2. `ScrollProgress`
3. `PageCurtain`
4. `Navbar`
5. `main`
   - `HeroSection`
   - `AboutStats`
   - `MachinesSection`
   - `ProductsSection`
   - `FacilitiesSection`
   - `ContactSection`
6. `Footer`

The top-level page is a Server Component by default, while interactive pieces are explicit Client Components with `"use client"`.

## Existing Components

### Layout Components

- `Navbar`
  - Fixed transparent navbar over the hero.
  - Changes to white, blurred, compact state after scroll.
  - Includes desktop nav, CTA, and animated mobile menu.
  - Uses `navLinks` from `content.ts`.

- `Footer`
  - Four-column footer with brand, quick links, product list, and contact info.
  - Uses `footerProducts`, `navLinks`, and `site` from `content.ts`.

### Section Components

- `HeroSection`
  - Full viewport video hero using `/video_hero.mp4`.
  - Framer Motion entrance animation for label, headline, copy, CTAs, and scroll indicator.
  - Current headline: `THE PARTS BEHIND EVERY GREAT SHOE.`

- `AboutStats`
  - Company intro copy plus animated statistic cards.
  - Uses `AnimatedNumber`, `Reveal`, and `SplitHeadline`.

- `MachinesSection`
  - Data-driven grid from `machines` in `content.ts`.
  - Uses `MachineCard`.
  - Styled as photo-first dark image cards.

- `ProductsSection`
  - Data-driven grid from `products` in `content.ts`.
  - Uses `ProductCard`.

- `FacilitiesSection`
  - Facility hero image with scroll parallax.
  - Clickable image gallery with lightbox navigation.
  - Uses `Lightbox`.

- `ContactSection`
  - Client-side form with validation, simulated loading state, and success message.
  - No backend submission is wired yet.

### UI Components

- `AnimatedNumber`
  - Counts numbers once when the stat enters the viewport.
- `LenisProvider`
  - Initializes smooth wheel scrolling globally.
- `Lightbox`
  - Fullscreen image preview with previous/next and keyboard navigation.
- `MachineCard`
  - Photo card for machine capability data.
- `PageCurtain`
  - Initial page-load white curtain animation with `KORIN` text.
- `ProductCard`
  - Product image card with tag, title, description, and arrow icon.
- `Reveal`
  - Generic Framer Motion reveal wrapper using opacity, vertical movement, and blur.
- `ScrollProgress`
  - Fixed top scroll progress bar.
- `SplitHeadline`
  - Splits heading text into animated word spans.

## Data Model

Most content is plain exported arrays/objects in `content.ts`:

- `site`
  - Name, email, phone, Tangerang address, Cirebon address, facility label, hours, and hero video path.
- `navLinks`
  - Anchor links for about, machines, products, facilities, and contact.
- `marqueeItems`
  - Manufacturing capability phrases.
- `stats`
  - Animated metric cards. Current active machine count is `10+` after removing Pon Machine.
- `products`
  - Product tag, name, description, and image path.
- `machines`
  - Machine name, description, image path, and Lucide icon reference.
- `workflow`
  - Archived process data retained for future reuse with `components/_archive/WorkflowSection.tsx`.
- `facilitiesImages`
  - Facility gallery source paths and alt text.
- `footerProducts`
  - Footer product list.

## Design System

The design is controlled by global class selectors in `app/globals.css`; there are no CSS Modules or component-scoped styles. The stylesheet is now organized as variables, reset, base typography, utilities, global effects, navigation, sections/components, animations, and responsive rules.

### Visual Direction

- Fullscreen dark video hero.
- White/light gray content sections.
- Red accent for CTAs and emphasis.
- Navy/blue as a secondary corporate color.
- Large condensed uppercase headings.
- Photo-first machine cards.
- Grid-based content sections with strong spacing.
- Subtle grain overlay on the body.
- Motion-heavy page experience.

### Layout Primitives

- `.section-shell` constrains content to `min(100% - var(--section-x) * 2, 1440px)`.
- `--section-x` controls responsive horizontal padding: `clamp(20px, 5vw, 72px)`.
- Main sections use large vertical padding: `clamp(5rem, 10vw, 9rem)`.
- Grids are used for about, products, machines, workflow, facilities, contact, and footer.
- Responsive breakpoints: `1100px`, `900px`, `768px`, and `720px`.

### Color Palette

CSS custom properties:

- `--color-bg`: `#ffffff`
- `--color-surface`: `#f5f5f3`
- `--color-surface-2`: `#ebebea`
- `--color-border`: `#e0e0de`
- `--color-primary`: `#c8102e`
- `--color-primary-dark`: `#a50d24`
- `--color-secondary`: `#1b3a6b`
- `--color-text`: `#031e40`
- `--color-text-body`: `#000000`
- `--color-muted`: `#888888`

Additional recurring colors:

- Near-black backgrounds: `#0f0f0f`, `#050505`, `#090909`
- White: `#ffffff`
- Success green: `#22C55E`, `rgba(46, 204, 113, ...)`
- Error text: `#ff7a8c`

### Typography

Fonts are defined in `app/layout.tsx` through `next/font/google`:

- DIN: self-hosted DIN Regular, Bold, and Black via `--font-din`
- Display fallback: Barlow Condensed via `--font-display`
- Body: Barlow via `--font-body`
- Mono: Space Mono via `--font-mono`

Headings and display titles now use the self-hosted DIN family through `--font-din`, with Barlow Condensed as fallback. `h1`, `h2`, `.hero-headline`, and `.flow-title` use DIN Black weight `900`.

### Animation Patterns

- Page load curtain via `PageCurtain`.
- Top scroll progress via `ScrollProgress`.
- Section reveals via `Reveal`.
- Word-level heading reveals via `SplitHeadline`.
- Hero mount animations.
- Animated stats via `AnimatedNumber`.
- Facility parallax in `FacilitiesSection`.
- Lightbox fade/scale transitions.
- Hover lift/scale effects on cards.
- CSS marquee keyframe for capability text.

## Notes For Future Agents

- Follow `AGENTS.md`: this repo uses Next.js 16, so read the local docs in `node_modules/next/dist/docs/` before changing Next-specific code.
- Prefer `content.ts` for content updates before touching components.
- Prefer keeping interactive/browser-specific components behind `"use client"`.
- `app/globals.css` is intentionally organized as variables, reset, base, utilities, global effects, navigation, components, animations, and responsive rules.
- Use `next/image` for local media where possible.
- Avoid broad design refactors unless the user asks, because the current design has a specific industrial, photo-led direction.
